## Shiro Elevadores

## Projeto Website da Shiro Elevadores

### Principais tecnologias aplicadas no Desenvolvimento Front End
- **GATSBY.JS** -> um framework gratuito e de código aberto baseado em **React** que ajuda desenvolvedores a criar sites e aplicativos extremamente rápidos;
- **Gatsby Image** -> é um componente React especialmente projetado para funcionar perfeitamente com as consultas GraphQL de Gatsby. Ele combina os recursos nativos de processamento de imagens de Gatsby com técnicas avançadas de carregamento de imagens para otimizar fácil e completamente o carregamento de imagens para seus sites;
- **GraphQL** -> uma linguagem de consulta para APIs e um ambiente de execução para atender a essas consultas com seus dados existentes.

### Recursos pré-instalados no template do projeto:
- **SHARP** -> processamento de imagens de alto desempenho;
- **STYLED-COMPONENTS** -> biblioteca de CSS-in-JS;
- **TYPOGRAPH** -> biblioteca de fontes com configuração mínima e Google Fonts;
- **REACT-ICONS** -> inclue ícones populares facilmente, utilizando importações ES6 que permitem incluir apenas os ícones que o seu projeto está utilizando;
- **STYLED-MEDIA-QUERY** -> utiliza media queries de forma mais fácil que o `@media` do CSS para styled-components, com a capacidade de definir breakpoints personalizados;
- **OFFLINE** -> adiciona suporte imediato para permitir que o site funcione offline e seja mais resistente a conexões de rede instáveis; isso cria um *service worker* para o site e o carrega no cliente;
- **SITEMAP** -> cria um mapa do site para o seu site em modo de produção;
- **MANIFEST** -> fornece configurações e ícones para o telefone (parte da especificação PWA); habilitado por este plugin, isso permite que os usuários adicionem seu site à tela inicial na maioria dos navegadores móveis;
- **PAGE-CREATOR** -> cria automaticamente páginas a partir de componentes React em diretórios especificados — gerando uma página para qualquer componente localizado na pasta ou nas subpastas de páginas designadas — e exclui automaticamente arquivos específicos, bem como padrões personalizados;
- **GLIDE.JS** -> componente de slider e carrossel JavaScript ES6 sem dependências. É leve, flexível e rápido. Projetado para deslizar. Nada mais, nada menos.
